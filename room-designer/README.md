# מעצב חדרים תלת-ממדי (Room Designer 3D)

אפליקציית עיצוב חדרים תלת-ממדית, עצמאית לחלוטין — ללא שרת, ללא תהליך בנייה (build),
וללא תלות בשאר האפליקציות שבריפו הזה.

## הרצה

פשוט פתחו את `room-designer/index.html` בדפדפן (לחיצה כפולה, או גרירה לחלון דפדפן).
אם מטעמי דפדפן מסוימים חלק מהתכנים לא נטענים דרך `file://`, אפשר גם להריץ שרת סטטי
קטן מתוך התיקייה הזו בלבד (למשל `npx serve .` או `python3 -m http.server`) —
זה **לא** קשור ול-`server.js` שבשורש הריפו ולא דורש אותו.

## פיצ'רים

- עריכת מידות חדר (רוחב/עומק/גובה), צבעי קיר/רצפה/תקרה, וחומרי רצפה (חלק/עץ/אריחים)
- מבט תלת-ממדי חופשי עם סיבוב/הזזה/זום (עכבר או מגע), עם קירות שנעלמים אוטומטית כשהם חוסמים את קו הראייה
- קטלוג של 16 פריטי ריהוט (בנויים כולם מגאומטריות פרימיטיביות — ללא קבצי מודל חיצוניים): ספה, כורסה, כיסאות, שולחנות, מיטות, ארונות, שידה, מזנון טלוויזיה, ספרייה, שטיח, מנורות ועציץ
- הוספה, גרירה למקום (עם הצמדה לרשת ומניעת חריגה מגבולות החדר), סיבוב, שינוי גודל, שינוי צבע, שכפול ומחיקה
- Undo/Redo מלא (Ctrl+Z / Ctrl+Y)
- שמירה וטעינה של פרויקטים (localStorage), ייצוא/ייבוא כקובץ JSON, וייצוא צילום מסך כ-PNG
- 3 תבניות פתיחה מוכנות: חדר שינה, סלון, חדר עבודה
- מצב תאורה יום/לילה (מנורות דולקות בלילה)
- ממשק רספונסיבי לנייד/טאבלט (תפריט צד וחלונית מאפיינים הופכים למגירות נגללות)

## קיצורי מקלדת

| מקש | פעולה |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | בטל / בצע שוב |
| `Ctrl+D` | שכפל פריט נבחר |
| `Delete` | מחק פריט נבחר |
| `Q` / `E` | סובב פריט נבחר |
| חצים | הזזה עדינה של פריט נבחר |
| `Esc` | ביטול בחירה |

## מבנה קבצים

```
room-designer/
  index.html        נקודת כניסה
  styles.css        עיצוב
  js/
    state.js         מצב הפרויקט, undo/redo
    materials.js      חומרים וטקסטורות קנבס
    scene.js          מצלמה, תאורה, renderer
    room.js           קירות/רצפה/תקרה
    catalog.js        קטלוג הריהוט
    interaction.js     raycasting והצמדה
    furniture.js       הוספה/בחירה/גרירה
    templates.js       תבניות פתיחה
    storage.js        שמירה/טעינה/ייצוא
    ui.js             חיווט הממשק
    main.js           אתחול
```
